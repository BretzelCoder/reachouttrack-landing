# reachouttrack-landing

Page d'attente statique (« coming soon ») pour `www.reachouttrack.org`,
hébergée sur GitHub Pages. Dépôt volontairement autonome et jetable : aucun
code partagé avec l'application ReachOutTrack.

- `index.html` — la page (autonome, styles inline, `noindex`)
- `CNAME` — domaine custom GitHub Pages

Mise à jour : éditer `index.html`, `git push` → redéploiement Pages en ~1 min.

Procédure complète (DNS OVH, activation Pages, HTTPS, bascule vers la landing
V1) : `docs/runbook-page-attente-github-pages.md` dans le dépôt applicatif.
